# React + TypeScript + Vite

## Setup

### Install nvm

Use installation script from [official github repository](https://github.com/nvm-sh/nvm)
Update shell after installation

```bash
exec $SHELL
```

### Install node 20.19

Using nvm install node 20.19

```bash
nvm install 20.19
```

### Install dependencies

```bash
npm i
```
